# 前端学习仓库

这是一个用于记录前端学习过程的仓库，包含学习笔记、练习项目和实战代码。

## 📂 目录结构

- **TodoList/**: 基于 React + Vite 开发的待办事项列表应用。
- **tic-tac-toe/**: React 官方教程中的井字棋游戏。
- **web/**: MDN Web Docs 学习笔记与代码，涵盖 HTML, CSS, JavaScript 基础。
- **practice/**: 日常练习的小项目。

## 🚀 项目介绍

### 1. TodoList

一个简单的待办事项管理工具。

- 技术栈: React, Vite
- 运行方式: 进入目录后运行 `npm install` 然后 `npm run dev`

### 2. Tic-Tac-Toe

React 入门教程的经典案例。

- 技术栈: React
- 运行方式: 进入目录后运行 `npm start`

### 3. Web 基础学习

收纳了前端三件套的学习笔记以及学习过程中用于查看效果的代码。

- 学习来源: [MDN Web Docs](https://developer.mozilla.org/zh-CN/docs/Learn_web_development)
